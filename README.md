# CodeAlpha Hangman Game

A simple text-based Hangman game developed using Python.

## Features

- Randomly selects a word from 5 predefined words
- Allows the player to guess one letter at a time
- Maximum 6 wrong guesses
- Displays the progress of the guessed word
- Handles repeated and invalid guesses

## Technologies Used

- Python
- Random module
- Lists
- Strings
- Loops
- Conditional statements

## How to Run

Run the following command:

python hangman.py
